PART 2 SQL SUBQUERY Implementation

Business Purpose: Filter and highlight only assignments that have uncompleted checklist subtasks (subtask.is_done = False), helping students prioritize pending work.

Inner Query: SELECT subtask.assignment_id FROM subtask WHERE subtask.is_done = FALSE

Outer Query: SELECT * FROM assignment WHERE assignment.id IN (<inner_query>)

2.2 Django ORM Code

# 1. Inner query: retrieve assignment IDs with unfinished subtasks
pending_subtasks = Subtask.objects.filter(is_done=False).values("assignment_id")

# 2. Outer query: filter assignments whose primary key is within the subquery
assignments = (
    Assignment.objects.filter(
        id__in=Subquery(pending_subtasks),
        user=request.user,
    )
    .select_related("subject", "status", "priority")
    .order_by("due_at")
)
